# ⛩️ 일본 여행 플래너

친구들과 함께하는 일본 여행 일정을 짜고 저장할 수 있는 웹앱입니다. 정적 파일(HTML/CSS/JS)만으로 동작하며, GitHub Pages로 배포되어 있습니다. 일정 데이터는 **Firebase(Firestore)** 에 저장되어, 이 페이지에 들어오는 모든 사람이 실시간으로 같은 일정을 보고 함께 수정할 수 있습니다.

## 주요 기능

- **여러 여행 관리**: 이름, 출발일/도착일, 같이 가는 친구들, 환율을 설정해 여러 여행을 만들고 전환
- **D-Day 카운트다운**: 출발일까지 남은 일수를 상단에 표시
- **날짜별 일정표**: 시간, 제목, 카테고리(교통/식사/관광/숙소/쇼핑/기타), 장소, 메모, 비용 입력
- **일정 순서 변경 & 시간순 정렬**: 위/아래 버튼으로 순서 조정, 버튼 한 번으로 시간순 자동 정렬
- **일정 검색**: 제목/장소/메모로 실시간 검색
- **예산 관리**: 일자별·전체 합계, 엔화→원화 환산(환율 직접 수정 가능), 1인당 분담금 자동 계산
- **준비물 체크리스트**: 일본 여행 기본 준비물 프리셋 + 항목 추가/삭제
- **여행 전 할 일 체크리스트**: 항공권, 숙소, 유심, 환전 등 기본 프리셋 + 커스텀 항목
- **장소 모아보기**: 일정에 입력한 장소를 구글 지도 링크로 모아보기
- **지도 (여러 핀 한번에 보기)**: 일정에 입력한 모든 장소를 하나의 구글 지도 위에 핀으로 표시 (Google Maps API 키 설정 필요, 아래 참고)
- **데이터 내보내기/불러오기**: JSON 파일로 저장해 친구와 공유하거나 백업
- **인쇄 / PDF 저장**: 인쇄용 레이아웃으로 전체 일정 출력
- **다크모드**: 우측 상단 버튼으로 전환
- **실시간 공유 저장**: Firebase(Firestore)에 저장되어, 이 사이트에 접속한 모든 사람이 실시간으로 같은 일정을 보고 함께 추가/수정/삭제할 수 있습니다 (로그인 불필요)

## 사용 방법

브라우저에서 바로 열거나(`index.html`), GitHub Pages로 배포된 주소로 접속하면 됩니다. 별도 설치나 빌드 과정이 필요 없습니다.

> 이 앱을 실제로 쓰려면 아래 "Firebase 설정" 과정을 먼저 완료해야 합니다. 설정 전에는 상단에 안내 배너가 뜨고 일정 저장이 동작하지 않습니다.

## Firebase 설정 (최초 1회, 관리자가 진행)

이 프로젝트는 **모든 방문자가 같은 데이터를 보고 편집**할 수 있도록 Firebase Firestore를 "완전 공개(누구나 읽기/쓰기)" 모드로 사용합니다. 링크를 아는 사람뿐 아니라 URL을 알아낸 누구든 데이터를 수정/삭제할 수 있다는 뜻이니, 여행 계획처럼 민감하지 않은 용도로만 사용하세요.

1. **Firebase 프로젝트 만들기**
   - https://console.firebase.google.com 접속 → 구글 계정으로 로그인
   - "프로젝트 추가" → 프로젝트 이름 입력(예: `japan-trip-planner`) → 애널리틱스는 꺼도 무방 → 프로젝트 생성

2. **Firestore 데이터베이스 만들기**
   - 좌측 메뉴 "빌드" → "Firestore Database" → "데이터베이스 만들기"
   - 위치(리전)는 가까운 곳(예: `asia-northeast3` 서울)으로 선택
   - 모드는 "테스트 모드"로 시작해도 되고, 아래 3번 규칙을 바로 적용해도 됩니다

3. **보안 규칙 설정** (모두가 읽고 쓸 수 있도록)
   - Firestore Database → "규칙(Rules)" 탭에서 아래 내용으로 교체 후 "게시(Publish)"
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /trips/{tripId} {
         allow read, write: if true;
       }
     }
   }
   ```

4. **웹 앱 등록 & 설정값 복사**
   - 프로젝트 개요 옆 톱니바퀴 → "프로젝트 설정" → "일반" 탭 → "내 앱" → 웹 아이콘(`</>`) 클릭
   - 앱 닉네임 입력 후 등록 (Firebase Hosting은 설정하지 않아도 됩니다)
   - 화면에 나오는 `firebaseConfig` 객체(apiKey, authDomain, projectId 등)를 복사

5. **이 저장소의 `firebase-config.js`에 붙여넣기**
   - 저장소 루트의 `firebase-config.js` 파일을 열어 `YOUR_API_KEY_HERE` 등 자리표시자 값을 4번에서 복사한 실제 값으로 교체
   - 커밋 후 `main` 브랜치에 푸시하면 GitHub Pages에 자동 반영됩니다 (배포까지 1~2분 소요)
   - 참고: 이 config 값들은 비밀키가 아니라 공개되어도 안전한 "웹 앱 식별자"이며, 실제 보안은 3번의 Firestore 규칙이 담당합니다

설정이 끝나면 사이트 상단에 "🌐 실시간 공유 중" 배지가 뜨고, 여행을 만들면 다른 방문자의 화면에도 실시간으로 반영됩니다.

## Google Maps 설정 (선택, "🗺 지도" 탭에서 여러 핀을 한 지도에 보려면 필요)

일정/예산 창의 장소 미리보기(핀 1개)와 "📍 장소 모아보기" 탭은 API 키 없이도 바로 동작합니다. 다만 "🗺 지도" 탭에서 **모든 장소를 하나의 지도 위에 여러 핀으로 함께 보려면** Google Maps JavaScript API 키가 필요합니다.

1. **Google Cloud 프로젝트 만들기**
   - https://console.cloud.google.com 접속 → 프로젝트 생성(또는 기존 프로젝트 선택)

2. **필요한 API 사용 설정**
   - 좌측 메뉴 "API 및 서비스" → "라이브러리"에서 **"Maps JavaScript API"** 와 **"Geocoding API"** 를 각각 검색해 "사용 설정"

3. **API 키 발급**
   - "API 및 서비스" → "사용자 인증 정보" → "+ 사용자 인증 정보 만들기" → "API 키" 선택 → 키 생성
   - (권장) 생성된 키를 클릭 → "애플리케이션 제한사항"에서 "HTTP 리퍼러"를 선택하고 이 사이트 주소(예: `https://<username>.github.io/*`)를 등록해 키 도용 방지

4. **이 저장소의 `maps-config.js`에 붙여넣기**
   - 저장소 루트의 `maps-config.js` 파일을 열어 `YOUR_GOOGLE_MAPS_API_KEY_HERE` 값을 3번에서 발급받은 키로 교체
   - 커밋 후 `main` 브랜치에 푸시하면 GitHub Pages에 자동 반영됩니다

키를 설정하지 않아도 나머지 기능은 모두 정상 동작하며, "🗺 지도" 탭에서만 안내 메시지가 표시됩니다. 개인 여행 플래너 수준의 사용량이면 Google Cloud의 매달 무료 크레딧 안에서 충분히 무료로 쓸 수 있습니다.

## 로컬 실행

```bash
python3 -m http.server 8000
# 이후 http://localhost:8000 접속
```
